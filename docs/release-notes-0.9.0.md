NEXVARY Recorder Studio 0.9.0 — Child and Family Safety Expansion preview

Development snapshot: encrypted local safety state, check-in countdowns, trusted contacts, emergency profile, alert queue, evidence integrity, guarded settings and real Google Play client integration. Existing recorder and SMTP tests remain part of every gate.

Cloud push/upload and live purchase verification have no configured backend. Their interfaces are separate from real SMTP delivery; the application does not claim cloud delivery or a purchased entitlement. Debug preview access is explicitly separate from paid ownership. Basic SOS stays available.

No physical Android device has been tested in this session. Background timing can be delayed without precise-alarm access or by force-stop/OEM restrictions. Camera and microphone recording require visible user interaction; reboot does not silently start them. Direct SMS and Accessibility interception are not requested.

The release candidate AAB is unsigned, for review and owner signing configuration; it is not a production-ready Play listing. This preview uses the public development APK identity. Do not merge main or claim all requested expansion features are complete based on build success.
