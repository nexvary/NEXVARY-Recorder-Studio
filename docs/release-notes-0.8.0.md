NEXVARY Recorder Studio 0.8.0 — timed camera recording and optional SMTP delivery

- Camera screen: optional 1–1440 minute timer, enabled before capture. Android MediaRecorder enforces the duration starting with actual capture, including while the activity is stopped. Manual Stop and save remains available. UI status and notification stop action are localized.
- Explicit per-recording email opt-in, one validated recipient. After stopping and validating the finalized MP4, an app-private outbox copy is prepared; the local original is never removed by delivery. A private pending copy is independent of later library moves/deletes. There is no automatic cloud upload or large-file link fallback.
- SMTP configuration in Settings and Camera: host, port, STARTTLS or direct TLS, authenticated account, sender and MIME-message-size limit. All saved configuration fields use AES-GCM with an Android Keystore key in noBackupFilesDir. Password input is not saved in activity state; its page prevents screenshots. Server/account changes require re-entry of the password. Connection test authenticates without sending a message.
- Eclipse Angus Mail 2.0.5 (officially supports Android) handles SMTP/MIME; Angus Activation 2.0.2. Trusted certificates and server identity checks are mandatory, TLS 1.2/1.3 only, no plaintext fallback or protocol traces. Local message limits include base64 overhead and an allowance for headers; the advertised SMTP SIZE limit is also checked. Attachment data is streamed.
- WorkManager 2.11.2 queues network-constrained expedited work on Android 12+ with normal-work fallback (normal constrained work on older Android) and bounded pre-DATA connection retries. Android battery/Doze/scheduling restrictions can delay sending. Outbox shows server acceptance (not a delivery/read guarantee), authentication/TLS/size/storage failures and cancellation/retry actions.
- SMTP cannot guarantee exactly-once delivery after an interrupted DATA exchange. Such jobs are marked Unconfirmed, do not automatically resend and require explicit retry confirmation. A stable Message-ID helps identify repeated attempts. No credentials or attachment bytes are stored in WorkManager input data. Pending jobs use current SMTP settings.
- Arabic and English labels added for the new feature. Other existing app languages use English for these new labels.
- Test SMTP connections use only loopback fixtures and public test-only TLS material. No real recipient/server is contacted by tests. Emulator uses the same AOSP API 35 image with a synthetic back camera enabled for real timed/manual MP4 tests. Hardware/OEM camera behavior still requires physical-device validation.

Preview uses the same public development signing identity as 0.7.1/0.7.2 with versionCode 12, supporting in-place preview updates. No merge to main. Live SMTP verification against the owner's server remains pending in-app configuration; no server secrets were requested in chat.
