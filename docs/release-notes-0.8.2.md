NEXVARY Recorder Studio 0.8.2 — smaller camera recordings and email size budgets

- Camera capture now defaults to Small file: H.264 target 320 kbps, up to 640×480, 15 fps where supported; optional AAC mono at 32 kbps / 16 kHz. Balanced targets 720p / 1.2 Mbps / 24 fps, High retains 1080p / 5 Mbps / 30 fps with higher audio quality. Each mode selects a size actually advertised by the camera without cropping or stretching. If no size fits the target, the smallest advertised size is used. Camera FPS ranges are selected from advertised capabilities.
- Quality selection is explicit, remembered, restored after rotation and passed to the actual recorder service before capture. Quality controls are disabled during recording. Existing recordings are not modified. Small files trade fine details, motion and low-light clarity for size; Android encoders can adjust requested rates, so no fixed size is guaranteed on all devices.
- The camera screen estimates one minute and five minutes, includes optional audio and MIME/base64 expansion, and shows the selected timer duration estimate and configured SMTP limit when email is enabled. A 25% estimate margin triggers a visible warning for likely oversized messages. Nominal five-minute compact recording with audio is about 13.3 decimal MB before MIME expansion, versus about 192 MB at the previous high-quality target.
- Estimates do not bypass the real file-size limit: the existing outbox checks actual finalized size and SMTP-advertised SIZE before submission. Local originals remain available on failed/oversized email. Very long clips can still exceed email limits: automatic segmentation, cloud upload and link delivery are not implemented in this release. A smaller file is not a guarantee of immediate delivery or inbox receipt.
- Regression gates include preset/size/budget unit tests, real Android quality selection, rotation/persistence and budget warnings, and an actual 60-second compact camera capture with microphone while the screen is off. The test checks playable H.264/AAC tracks, mono audio, resolution, duration, a size below 4.5 decimal MB, no email enqueue, and exports measured bytes/duration/dimensions to diagnostics/quality-measurements.json. All recordings and email tests use the synthetic emulator camera or local SMTP fixtures; no real recipient is contacted.
- Actual screenshots include the new Arabic quality controls. Arabic and English labels are provided; other existing locales use English for the new labels. SMTP configuration and prior UI features are preserved. The owner confirmed SMTP connectivity in 0.8.1; this release does not claim physical OPPO encoding validation.
