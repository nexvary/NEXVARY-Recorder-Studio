# Guardian Studio 0.11.2

Settings, appearance, family configuration, account/service connection and the
development SMTP diagnostic page now allow screenshots after the guardian gate
has opened. Users can send images of the connection fields to support.

The PIN prompt and locked content remain protected. Private recordings, PIN
configuration, trusted contacts, emergency profiles and history retain their
existing capture protection. Password fields remain masked.

Instrumentation covers settings recreation, successful PIN entry, relocking,
and capture protection on sensitive family pages. Live service activation and
physical OPPO/ColorOS verification remain separate deployment/device tasks.
