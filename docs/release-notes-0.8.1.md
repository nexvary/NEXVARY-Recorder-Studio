NEXVARY Recorder Studio 0.8.1 — SMTP setup corrections and useful connection errors

- Entering port 465 now selects direct TLS; entering 587 selects mandatory STARTTLS, including Arabic/Persian numerals. Custom ports keep an explicit security choice. Previously only changing the TLS switch updated the port; editing the port could leave incompatible security selected.
- The connection test is explicitly labeled Test connection and save settings. Successful TLS authentication now persists exactly the tested profile in Android Keystore-backed encrypted storage. Previously testing did not save the settings. A failed test preserves the previous saved profile. Storage failure after successful authentication has its own message. Manual save remains available without network access.
- SMTP setup now distinguishes DNS lookup, connection refusal, timeout, TLS/certificate, authentication and missing STARTTLS failures. Only fixed Arabic/English guidance and codes are displayed; raw server responses and credentials are never shown or logged. No certificate checks were disabled and no email is submitted by the test action.
- Host validation rejects schemes, paths and embedded ports before connecting, with a specific explanation. Fields and save/test/remove actions are disabled during operations so editing cannot silently replace a different tested profile.
- Regression tests cover real loopback TLS and STARTTLS authentication with zero DATA submissions; save-after-test and failed-test preservation; nested error classification; actual Android port controls, encrypted settings reopening and password retention. Existing timer, MP4, navigation, outbox and visual gates continue to run. SMTP credentials page keeps FLAG_SECURE, so no screenshot of that page is published.

The reported screenshot shows the recording screen after saving, not the SMTP failure itself. These corrections address verified setup/diagnostic defects; the cause on the owner's server cannot be confirmed without its non-secret host/port/security and displayed error category. No owner SMTP account or external recipient was contacted. Physical OPPO testing remains unavailable. New diagnostics are Arabic and English, with English fallback for other existing locales.
